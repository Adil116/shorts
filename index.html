Шортсы пачкой, за один заход

Бросьте видео и текст от ИИ: приложение подставит каждому шортсу своё название и теги, добавит ссылку на длинное видео и загрузит всё на ваш канал.

1

Подключение к YouTube

Не подключено

Где взять Client ID (один раз, ~10 минут)
  1. Откройте console.cloud.google.com, создайте проект и включите «YouTube Data API v3».
  2. «Экран согласия OAuth»: тип «Внешний», добавьте свою почту в «Тестовые пользователи».
  3. «Учётные данные» → «Создать» → «Идентификатор клиента OAuth» → «Веб-приложение».
  4. В «Разрешённые источники JavaScript» впишите адрес, где открыта эта страница (например https://ваш-логин.github.io или http://localhost:8080). Файл, открытый двойным кликом (file://), не подойдёт.
  5. Скопируйте Client ID сюда. При входе Google скажет «приложение не проверено»: нажмите «Дополнительно» → «Перейти». Это ваше личное приложение.

Параметры публикации
